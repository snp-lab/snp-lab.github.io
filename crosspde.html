CrossPDE
We have developed a prototype of CrossPDE by modifying the existing open-source code. Utilizing the hidden volume technique, CrossPDE can securely conceal sensitive data while maintaining compatibility with the storage architecture of mainstream mobile devices. It is lightweight and user-oriented. The key idea of CrossPDE is to intercept major layers of a mobile storage system, including the file system layer (preventing loss of hidden sensitive data and enabling users to use the hidden mode), the block layer (taking care of expensive encryption and decryption), and the flash translation layer (eliminating traces caused by the hidden sensitive data). The current source code of CrossPDE is avaiable here (Please be aware that the source code is intended solely for research and study purposes, and comes with no warranty).
