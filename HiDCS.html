HiDCS
HiDCS is a Hardware-assisted integrity-assured Decentralized Cloud Storage system. It relies on two trusted components: 1) trusted execution environment which is a secure area of the processor, and 2) flash translation layer which is the firmware encapsulated in the flash storage hardware. Using these two components, HiDCS enables self-audit, while also explicitly preventing both outsourcing and generation attacks. Additionally, HiDCS enables self-repair, which attempts to fix corrupted data using only local resources, thereby eliminating the significant communication overhead typically associated with repairs over time.. The current prototype implementation is specific for the Intel SGX and the embedded board LPC-H3131 which runs an open-source flash controller OpenNFM. The detailed description of the system can be found in our HiDCS paper.
