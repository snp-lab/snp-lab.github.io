PBL-online
We have been developing software vulnerabilities puzzles for online teaching of software security (CS4740/5740: Development of Trusted Software, in the Department of Computer Science, Michigan Technological University). The puzzles have been used for our online teaching during Spring 2025 and Spring 2026. A list of the developed puzzles is as follows:
- A command injection puzzle that tests student input into a system() command, allowing for arbitrary code.
- A buffer overflow/ROP puzzle in which students use gdb in order to find the memory address of system commands to run them, giving them access to arbitrary code execution.
- A heap overflow puzzle by which students can understand the heap overflow vulnerability.
- A time-of-check/time-of-use (TOCTOU) puzzle where students must validate that a file is not a ``secret," then change that file to a symlink to the secret between validation and use.
- An entirely web-based cross-site scripting puzzle in which students can input arbitrary HTML to a page and test it.
