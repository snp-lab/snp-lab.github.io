DRFlash
DRFlash is a prototype developed by the SnP lab. The tool aims to recover the data deleted by the user (or the malware like ransomware) in the computing devices using flash memory as the external storage. A key idea is to extract the raw flash memory data inside the flash storage medium, so that the data deleted by the user or the malware can be recovered. The current prototype implementation is specific for the embedded board LPC-H3131 and integrated with an open-source flash controller OpenNFM.
