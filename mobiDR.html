mobiDR
mobiDR was developed to enable recoverability of user data at the corruption point against the strong OS-level malware. The key idea is to build a secure version control system virtually across the mobile device and the version control server in an adversarial setting, such that the most recent delta data are correctly maintained in the mobile device and the historical delta data are correctly stored in the cloud server. In this manner, any version of data is recoverable in the mobile device hence the version of data at the corruption point is always recoverable. The current prototype implementation is specific for the embedded board LPC-H3131 and integrated with an open-source flash controller OpenNFM. The detailed description of the software can be found in our mobiDR paper.
